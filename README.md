# Agent Office — Mac download

A customized personal build of [bas3line/agent-office](https://github.com/bas3line/agent-office), with a pixel office, Codex-style chats, Watch Room and Spotify.

**[Download Agent Office for Apple Silicon Macs](https://github.com/iso000/agent-office-downloads/releases/latest/download/Agent-Office-Apple-Silicon.dmg)**

Requires an M-series Mac and macOS 13.5 or later. Open the DMG, drag Agent Office to Applications, then open it. The runtime is included; Homebrew, Node.js and Terminal setup are unnecessary. Use your own Codex/agent and streaming-service accounts.

This personal build is ad-hoc signed and is not Apple notarized. macOS may require a manual approval under System Settings → Privacy & Security after the first open attempt. Read [Apple’s first-open guidance](https://support.apple.com/en-us/102445) before approving. No security protections are disabled by the installer.

The release contains no developer chats, passwords, cookies, credentials, personal settings or browser profiles. Its first launch sets up only its own local runtime and Office service; it does not configure MCP servers or change Codex/Kimi settings. The service starts at login and can be managed inside Office. The personal installation’s custom recovery guard is not part of the shared build.

Installation details and SHA256 checksums accompany each release. This repository contains downloads and installation notes; it does not mirror the private customization repository. Upstream attribution and third-party license notices are bundled in the app. This is an independent personal build, not an official OpenAI, Spotify or streaming-service application.
